1️⃣ What is JWT and why is it used in backend applications?

JWT (JSON Web Token) is a compact, secure way to transmit information between client and server.

It is mainly used for:

✅ Authentication (login system)

✅ Authorization (protecting routes)

✅ Secure data transfer

Instead of storing session data in server memory, JWT sends a token to the client after login. The client sends that token in every request.

2️⃣ What are the three parts of a JWT token?

A JWT has 3 parts separated by dots:

HEADER.PAYLOAD.SIGNATURE
1. Header

Contains:

Algorithm (e.g., HS256)

Token type (JWT)

2. Payload

Contains:

User data (id, email, role, etc.)

3. Signature

Ensures token is not modified.

Example:

eyJhbGciOiJIUzI1NiIsInR5cCI6IkpXVCJ9
.
eyJpZCI6IjEyMyIsImVtYWlsIjoiYWJjQGdtYWlsLmNvbSJ9
.
SflKxwRJSMeKKF2QT4fwpMeJf36POk6yJV_adQssw5c
3️⃣ Difference between Payload and Signature
Payload	Signature
Contains user data	Verifies token integrity
Can be decoded	Cannot be faked without secret key
Not encrypted by default	Created using secret key

👉 Payload = Information
👉 Signature = Security

4️⃣ What is the purpose of jwt.sign()?

Used to create a token.

jwt.sign(payload, secretKey, options)

Example:

const token = jwt.sign(
  { id: user._id },
  process.env.JWT_SECRET,
  { expiresIn: "1h" }
);

It:

Takes payload

Uses secret key

Generates signed token

5️⃣ What is the purpose of jwt.verify()?

Used to check if token is valid.

jwt.verify(token, secretKey)

It:

Checks signature

Checks expiration

Returns decoded payload if valid

Throws error if invalid

6️⃣ Why should JWT secret keys be stored in .env file?

Because:

🔐 Secret key must be private

❌ Never push to GitHub

✅ .env keeps sensitive data secure

Example:

JWT_SECRET=mySuperSecretKey123

And use:

process.env.JWT_SECRET
7️⃣ What happens if verification secret is different?

If the secret used in jwt.verify() is different from jwt.sign():

👉 Token verification fails
👉 Error: invalid signature

Server will reject the request.

8️⃣ What does expiresIn option do?

It sets token expiration time.

Example:

{ expiresIn: "1h" }

Means token is valid for 1 hour.

After that:

jwt.verify() throws TokenExpiredError

9️⃣ How do you send JWT from backend to client?

Usually in login response:

res.status(200).json({
  message: "Login successful",
  token: token
});

OR inside cookies:

res.cookie("token", token, { httpOnly: true });
🔟 Where should client send JWT for protected routes?

In request headers:

Authorization: Bearer <token>

Example using axios:

axios.get("/api/protected", {
  headers: {
    Authorization: `Bearer ${token}`
  }
});
1️⃣1️⃣ Status code if token is missing?

👉 401 Unauthorized

res.status(401).json({ message: "Token missing" });
1️⃣2️⃣ Status code if token invalid or expired?

👉 403 Forbidden (commonly used)

OR sometimes:

👉 401 Unauthorized

Best practice:

401 → No token

403 → Invalid/expired token

1️⃣3️⃣ Authentication vs Authorization
Authentication	Authorization
Who are you?	What can you do?
Login process	Access control
Verify user identity	Check user role

Example:

Login → Authentication

Admin dashboard access → Authorization

1️⃣4️⃣ Why is JWT stateless?

Because:

Server does NOT store session data

All user info is inside token

Each request contains everything needed

No session memory needed.

👉 That’s why JWT is scalable.

1️⃣5️⃣ How do you protect a route in Express?

Create middleware:

import jwt from "jsonwebtoken";

export const authMiddleware = (req, res, next) => {
  const authHeader = req.headers.authorization;

  if (!authHeader) {
    return res.status(401).json({ message: "Token missing" });
  }

  const token = authHeader.split(" ")[1];

  try {
    const decoded = jwt.verify(token, process.env.JWT_SECRET);
    req.user = decoded;
    next();
  } catch (error) {
    return res.status(403).json({ message: "Invalid token" });
  }
};

Use in route:

router.get("/dashboard", authMiddleware, (req, res) => {
  res.json({ message: "Protected route accessed" });
});
