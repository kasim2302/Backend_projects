   Normally js runs in browser in v8 engine then Nodejs let us to run js outside the browser.

   why we use it in backend:
   - Fast (uses V8 engine)
   - Non blocking asynchronus
   - Good for API and real time apps
   - uses same language for frontend & backend.
    
  Example use:
   - To create REST APIs
   - Connecting to database
   - Handling authentication

2. Difference between synchronous and asynchronous functions?
  Synchronus(blocking):
   - code runs line by line.
   - Next line waits until previous line finishes.

   const data = fs.readFileSync("file.txt)
   console.log(data)

   Asynchronus(Non-blocking):
   - Does not wait for the previous process
   - Other code can run while task is processing.

    fs.readFile("file.txt",(err,data)=>{
    console.log(data)
    console.log("Error",err)
   })

   Nodejs is famous because of Asynchronus behavior.

6.What is routing in Express?

Defining how the server responds to client requests.


Example:

app.get("/users", (req, res) => {
   res.send("User list");
});

Here:

/users = route

app.get() = method

Callback handles request

8. What is the response object (res)?

res is the response object.

It sends data back to client.

Common methods:

res.send()

res.json()

res.status()

Example:

res.status(200).json({ message: "Success" });

Without res, client will never get response.

9. What is the use of HTTP status codes?

Status codes tell the client:
👉 Whether request was successful or not.

Common codes:

200 → Success

404 → Not Found

500 → Server Error

201 → Created

400 → Bad Request

Example:

res.status(404).send("User not found")

 JSON-like format (BSON documents)

Difference: MongoDB vs SQL
SQL	MongoDB

12. What is Mongoose?

Mongoose is an ODM (Object Data Modeling) library for MongoDB in Node.js.

It helps:

Create schemas

Validate data

Interact with MongoDB easily

Without Mongoose → Raw MongoDB commands
With Mongoose → Clean structured code

13. What is a Schema in Mongoose?

Schema defines:
👉 Structure of a document

Example:

const userSchema = new mongoose.Schema({
   name: String,
   age: Number
});

It defines:

Field names

Data types

Validation rules

14. What is a Model in Mongoose?

Model is created using schema.

const User = mongoose.model("User", userSchema);

Model is used to:

Create

Read

Update

Delete documents

Think:
Schema = Structure
Model = Tool to interact with DB
